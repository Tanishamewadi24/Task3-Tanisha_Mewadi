# Task3-Temperature Converter Website

## Objective

Created an interactive temperature converter that converts values between Celsius, Fahrenheit, and Kelvin using JavaScript.

## Implemented

* Temperature input field with numeric validation
* Unit selection for Celsius, Fahrenheit, and Kelvin
* Conversion between all three temperature units
* Result display with proper unit labels
* Error message for invalid or empty input
* Clean and centered user interface
* Responsive layout for mobile devices
* Hover and focus effects for better user experience
  
## Technologies

* HTML5
* CSS3
* JavaScript
* Google Fonts
